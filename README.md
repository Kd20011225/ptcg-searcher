# 宝可梦卡牌查卡器

供个人查卡使用的简体中文宝可梦卡牌搜索网页。支持卡名、效果、系列、属性、规则框、撤退费用，以及特性／招式来源筛选。

包含 21,705 张卡面与本地 WebP 卡图。可通过浏览器添加到手机主屏幕；页面、卡库及已缓存卡图支持离线访问。

网页地址：https://kd20011225.github.io/ptcg-searcher/ （GitHub Pages 发布成功后生效）。

朋友可直接用电脑或手机浏览器打开，无需登录 GitHub，也无需原作者的电脑保持开机。iPhone 可在 Safari 分享菜单选择“添加到主屏幕”；安卓与鸿蒙可在支持此功能的浏览器菜单中添加快捷方式。

第一次访问需要联网，卡图按查看需要加载；离线时仅能显示已缓存的卡图。

本仓库为静态网页发布内容，由本地项目构建生成。

卡牌文字及卡图来自社区简中卡牌数据集 https://github.com/duanxr/PTCG-CHS-Datasets ，未逐张通过官方核对。本项目不是官方产品。
